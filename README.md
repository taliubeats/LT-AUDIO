# LT AUDIO

Familia de plugins de audio **LT** (VST3 / AU) para Mac y Windows.

| Plugin | Qué es |
|---|---|
| LT TYPE BEATS | Analizador de BPM, tonalidad y acordes (con link de YouTube) |
| LT PULSAR | Sidechain / ducking |
| LT KNOCK | Procesador de drums y melodías |
| LT NEBULA | Granular |
| LT ORBIT | Delay |
| LT VOID | Reverb |
| LT LICENSE STUDIO | App de Mac para generar licencias |

Todo el diseño y las decisiones: [`docs/DESIGN.md`](docs/DESIGN.md). Imágenes de referencia: [`design/`](design/).
